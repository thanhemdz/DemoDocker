Docker là gì?

Nền tảng container hóa mã nguồn mở

Docker là một nền tảng mã nguồn mở cho phép các nhà phát triển đóng gói ứng dụng cùng với toàn bộ phụ thuộc vào một đơn vị chuẩn hóa gọi là container.

Không còn tình trạng "chạy được trên máy tôi mà không chạy được trên máy anh". Container đảm bảo ứng dụng chạy nhất quán trên mọi môi trường: development, testing, và production.

Tính năng nổi bật

Tại sao chọn Docker?

Docker cung cấp những công cụ mạnh mẽ giúp đơn giản hóa quy trình phát triển và triển khai phần mềm.

⚡

Khởi động cực nhanh

Container khởi động trong vài giây, nhanh hơn máy ảo VM hàng chục lần. Tiết kiệm thời gian phát triển đáng kể.

🔒

Cô lập an toàn

Mỗi container chạy trong môi trường cô lập riêng biệt, đảm bảo các ứng dụng không ảnh hưởng lẫn nhau.

📦

Đóng gói hoàn chỉnh

Toàn bộ code, thư viện, và cấu hình được gói trong một image duy nhất, dễ dàng chia sẻ và deploy.

🌐

Hệ sinh thái rộng lớn

Docker Hub cung cấp hàng triệu image sẵn có từ cộng đồng: nginx, postgres, redis, và nhiều hơn nữa.

📈

Mở rộng dễ dàng

Docker Compose và Kubernetes giúp quản lý ứng dụng microservices với nhiều container một cách hiệu quả.

💰

Tiết kiệm tài nguyên

Container chia sẻ kernel của host OS, sử dụng ít RAM và CPU hơn VM, tối ưu chi phí hạ tầng.

Cách hoạt động

Bắt đầu với Docker

Chỉ vài bước đơn giản để chạy ứng dụng đầu tiên của bạn trong container.

1

Cài đặt Docker

Tải và cài đặt Docker Desktop cho Windows/macOS hoặc Docker Engine cho Linux.

curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
2

Tạo Dockerfile

Viết Dockerfile mô tả môi trường chạy ứng dụng của bạn.

FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
EXPOSE 3000
CMD ["node", "index.js"]
3

Build Image

Chạy lệnh build để tạo Docker image từ Dockerfile.

docker build -t my-app:1.0 .
4

Chạy Container

Khởi chạy container từ image vừa tạo và truy cập ứng dụng.

docker run -d -p 3000:3000 --name my-app my-app:1.0
5

Quản lý với Docker Compose

Sử dụng Docker Compose để quản lý nhiều container cùng lúc.

docker compose up -d
docker compose down
docker compose logs -f
So sánh

Docker vs Máy ảo (VM)

Hiểu sự khác biệt giữa container và máy ảo truyền thống.

🖥️ Máy ảo (VM)

  • ✗ Khởi động mất vài phút
  • ✗ Dung lượng GB cho mỗi VM
  • ✗ Tiêu thụ nhiều RAM/CPU
  • ✗ Phụ thuộc Hypervisor
  • ✓ Cô lập hoàn toàn cấp OS
  • ✓ Bảo mật cao hơn

🐳 Docker Container

  • ✓ Khởi động trong vài giây
  • ✓ Image nhỏ gọn (MB)
  • ✓ Chia sẻ kernel, tiết kiệm tài nguyên
  • ✓ Portable — chạy mọi nơi
  • ✓ CI/CD thân thiện
  • ✓ Hệ sinh thái phong phú

Lệnh Docker thường dùng

Tổng hợp các lệnh Docker hay dùng nhất trong quá trình phát triển.

🐋 Images

docker pull <image>Tải image về
docker imagesLiệt kê images
docker build -t name .Build image
docker rmi <image>Xóa image
docker push <image>Đẩy lên registry

📦 Containers

docker run -d <image>Chạy container
docker psXem container đang chạy
docker stop <id>Dừng container
docker rm <id>Xóa container
docker exec -it <id> shTruy cập container

🔍 Logs & Info

docker logs <id>Xem log
docker inspect <id>Thông tin chi tiết
docker statsTài nguyên thời gian thực
docker system dfDung lượng sử dụng
docker system pruneDọn dẹp tài nguyên

🎼 Compose

docker compose up -dKhởi động services
docker compose downDừng services
docker compose psXem trạng thái
docker compose logs -fXem log theo dõi
docker compose restartKhởi động lại
